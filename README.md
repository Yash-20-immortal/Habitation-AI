# Habitation-AI

Habitation-AI is a gamified habit-building platform that helps users develop productive routines through task tracking, XP rewards, streak monitoring, and AI-powered habit recommendations.

## Features

- User Registration and Login System
- Secure Password Hashing
- Habit and Task Management
- XP-Based Progress System
- Activity Tracking Dashboard
- Streak Monitoring
- AI-Powered Habit Suggestions
- Future XP Prediction
